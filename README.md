📌 Portfólio – Vinicius Gabriel

Este é o meu portfólio desenvolvido como parte da Atividade Final da disciplina de Desenvolvimento Front-End (UCB).
O projeto apresenta meus trabalhos, minha trajetória, um e-book interativo e uma galeria multimídia.

🚀 Tecnologias utilizadas

HTML5

CSS3

JavaScript

Figma (prototipação)

Vercel (deploy)

📚 Conteúdo do site

O portfólio contém as seguintes seções:

Home — Introdução e foto de perfil

Sobre mim — Minha trajetória e formação

E-book Interativo — Capítulo multimídia com texto expandido e vídeo

Projetos

TechRecycle (protótipo Figma)

iFruit (app Expo Go)

FreeCode (landing page)

Galeria — Prints, overview do Figma e um vídeo embutido

Contato — Formulário funcional com feedback ao usuário

🧠 Funcionalidades JavaScript

O site possui diversas interações JS:

Alternância entre tema claro/escuro

Menu mobile com animação

Modal de imagens da galeria

Animação de entrada via IntersectionObserver

Botão "Mostrar mais" do e-book

Scroll suave entre seções

Sistema de favoritos nos projetos (localStorage)

🖼️ Galeria multimídia

A galeria contém:

Imagens dos projetos

Overview de protótipos no Figma

Vídeo embutido em <video>

♿ Acessibilidade

Inclui:

alt em todas as imagens

aria-label em botões importantes

Navegação via teclado

skip-link para pular direto para o conteúdo

Contraste adequado entre texto e fundo
